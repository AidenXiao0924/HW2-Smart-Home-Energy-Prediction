# Dataset Attribution

本專案使用 **Appliances Energy Prediction** Dataset：

- Creator：Luis Candanedo
- Citation：Candanedo, L. (2017). *Appliances Energy Prediction* [Dataset]. UCI Machine Learning Repository.
- DOI：https://doi.org/10.24432/C5VC8G
- Official source：https://archive.ics.uci.edu/dataset/374/appliances+energy+prediction
- Dataset license：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

本專案執行時間順序切分、時間特徵工程、統計彙整、模型訓練及圖表抽樣。公開 Repository 不包含完整原始或切分後 Dataset；使用者需由 UCI 官方來源另行取得資料。上述資料授權獨立於本專案原始碼採用的 MIT License，且本專案不暗示 Dataset 作者或 UCI 對研究結果背書。

網站公開的聚合統計、凍結模型參數及 12 筆 Test Demo 最小資料，均記錄於版本化 Artifact／Manifest；Demo 不等同完整 Test Dataset，也不能代表整體模型表現。
